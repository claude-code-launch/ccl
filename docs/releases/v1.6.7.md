## 修复与改进

- 修复 npm 安装后 `ccl` 报 “ccl binary for … is not installed” 的问题。npm 在一次 `npm publish` 返回后还要处理 provenance 才对外提供元数据，1.6.6 发布时 launcher 比 `ccl-darwin-arm64` 早约 2 分钟可查；launcher 对平台包写的是精确版本，而 npm 对无法解析的 `optionalDependencies` 会静默跳过并返回 0，于是 launcher 装上了、平台包没装。现在：
  - 发布流程在发布 launcher 前逐个等待平台包可解析（最长 15 分钟），从源头消除该时间窗；
  - `postinstall` 找不到平台包时以非零退出码失败，不再留下一个首次运行才报错的 `ccl`；
  - 占位脚本的报错改为可直接执行的 `npm install -g @claudecodelaunch/ccl@<版本>`，无需先卸载；
  - `ccl update --method npm` 安装后校验新命令的版本，失败时自动改用直接下载二进制（Windows 无法替换运行中的可执行文件，提示稍后重跑同一条 npm 命令）。
- `ccl update` 的版本判断仍以 GitHub Release 为准，npm 未发布时不提供 npm 方式（1.6.6 已包含）。
