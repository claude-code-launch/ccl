## 修复：`ccl serve` 显示后台子代理

Claude Code 现在总是在后台运行子代理（Agent / Task）：调用会立刻返回 "launched"，真正的工作稍后才结束。此前页面把子代理当成瞬间完成，它的步骤折叠在一行里，看不出它在运行。

- 子代理运行期间卡片显示转圈，下方实时显示它最近的一步；结束后显示步数和耗时，被中断时显示"已停止"。
- 后台工作（子代理、后台 Bash）结束前，轮次保持"进行中"：Claude Code 会在后台工作完成后自动再回复一轮，这一轮的内容现在归入同一个轮次，结尾只有一个结果，用量合并计算。
- 后台子代理发起的权限请求在主回复结束后仍可回答。
- 后台工作结束后的那轮回复单独成段，不再与前文粘连。
