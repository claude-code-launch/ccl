## 修复 VS Code 扩展走 OpenAI Chat 网关时报 400

### 问题

在 VS Code 的 Claude Code 扩展里使用 WorkBuddy 一类 OpenAI Chat 网关时，每个请求都被上游拒绝：

```
API Error: 400 OpenAI Chat Completions upstream returned HTTP 400:
{"code":11128,"msg":"Illegal API invocation from an unapproved channel", ...}
```

终端里用同样的 provider 却正常。

### 原因

Claude Code 会在 system prompt 里带一行自我介绍，网关据此判断请求是否来自官方客户端，CCL 在转成 OpenAI Chat 格式时会把它剔除。但这一行随入口变化：

- 终端交互：`You are Claude Code, Anthropic's official CLI for Claude.`
- Agent SDK（VS Code 扩展走这条）：`You are Claude Code, Anthropic's official CLI for Claude, running within the Claude Agent SDK.`
- SDK 构建的 agent：`You are a Claude agent, built on Anthropic's Claude Agent SDK.`

旧代码只精确匹配第一种，后两种被原样转发，于是被渠道校验拦截。这也解释了为什么只有扩展里失败。

### 修复

- 身份行改为前缀匹配三种形态，并忽略其后的入口后缀。
- 身份行嵌在一大段指令里时只删掉该行，不再因为匹配不到而丢掉整块真正的指令。

只影响 OpenAI Chat Completions 的请求转换，其他协议不变。
