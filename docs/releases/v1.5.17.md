## 发布产物改为 gzip 压缩

- GitHub Release 中的二进制改为 gzip 压缩：每个约 28MB 压缩到约 10MB，文件名变为 `ccl-<平台>.gz`。`SHA256SUMS` 记录的是 `.gz` 文件的校验和。
- npm 包不变，仍然包含未压缩的二进制，`npm install -g @claudecodelaunch/ccl` 用法照旧。
- `ccl update` 的"自动更新"改为下载 `.gz` 并边下边解压，解压后超过 256MiB 会拒绝；原有的安全检查不变：确认是 ccl 可执行文件、平台匹配、保留旧版本备份。

**升级提示：** v1.5.16 及更早版本的"自动更新"只认未压缩文件，下载不到本版本，会报 HTTP 404。请用 npm（`npm install -g @claudecodelaunch/ccl@latest`）或 go（`go install github.com/claude-code-launch/ccl@latest`）更新一次，之后的自动更新恢复正常。手动下载时先解压：`gunzip ccl-darwin-arm64.gz`；Windows 的解压方法见 README。

## 发布流程提速

- GitHub Release 与 npm 发布改为两个并行的 job，不再先后执行。
- 资产改用 `gh release create` 并发上传，全部上传完成后才发布 release。
