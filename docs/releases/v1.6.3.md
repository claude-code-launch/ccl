## 新增

- `ccl acp --model <model>` / `--effort <level>`：新建、加载、恢复和分叉的会话直接使用指定的模型与推理强度，无需客户端选择。Xcode 27 不显示 ACP 模型选择器，可以添加多个参数不同的 Xcode agent，例如 `ccl acp --model opus --effort max`。指定的模型不可用时，会话保留原有模型。
- 仓库新增 `scripts/xcode-claude-link.sh`：把 Xcode 内置的 Claude agent 链接到本机的 `claude`，Apple 原版保留为 `claude.apple`。Xcode 更新 agent 后重新运行即可。

## 修复与改进

- Qoder：新版 Claude Code 会把 system 提示放进消息列表，包括工具结果之后的最后一条。此前这些提示按 system 原样转发，Qoder 背后的 GLM 会拒绝请求（`1214 messages 参数非法`）。现在对话开始后的 system 提示改为 user 消息发送。
- Gemini：消息列表中内容为 text 块的 system 提示不再被丢弃，改为 user 文本转发。
