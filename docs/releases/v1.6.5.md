## 新增

- 新增 `workbuddycn`：`ccl oauth workbuddycn` 登录 WorkBuddy 中国大陆站点（www.workbuddy.cn）。与 `workbuddy`（www.workbuddy.ai）使用同一套插件 API 与对话协议，仅 origin 不同；两边的账号与凭据完全隔离，credential `type` 分别为 `workbuddycn` / `workbuddy`，不会把一方的 token 发到另一方的站点。
- 模型选择器显示费率：订阅目录（WorkBuddy 的 `credits`，Qoder 的 `PriceFactor`）以及 Anthropic/OpenAI 兼容网关 `/models` 中的 `rate_multiplier`，会以 ` · 0.29x` 之类的标记出现在 `/model` 列表中；倍率为 0 的模型显示 ` · free`。`[1m]` 槽位沿用基础模型的费率。

## 修复与改进

- 订阅目录的费率元数据（`rate_multiplier`、`rate_unit`、`is_new`、`promotion_available`）不再在 OpenAI 兼容的 `/models` 解析中丢弃，与 Anthropic 兼容路径保持一致。
