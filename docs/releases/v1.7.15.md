## 按 WorkBuddy 倍率过滤模型选择器

### 问题

WorkBuddy 自己的模型列表只展示带积分倍率的对话模型（`0.15x`、`0.29x`、`0.00x` 等）。CCL 把账号 catalog 里的补全、绘图、视频以及未接入的 id 一并放进了 `/model`，选到后者会 11102。

### 修复

`buildWorkBuddyRoutes` 只保留 catalog 里带可解析 `credits` 的行（含 `x0.00` 免费模型）。补全 / 绘图 / 视频等没有倍率的 id 不再进入运行时路由和选择器。若整份 catalog 都没有倍率字段，仍保留全量，避免接口改版把模型池清空。
