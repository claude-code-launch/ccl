## 修复与改进

- npm 安装不再受发布后的索引延迟影响：npm 暂时没有提供平台包时，postinstall 会改从 GitHub Release 下载同一个二进制，用 `SHA256SUMS` 校验后放到原位置。下载或校验失败时安装仍会失败，并给出重试命令。`CCL_RELEASE_DOWNLOAD_URL` 可以替换下载的基础地址。
- npm 发布不再等待平台包可安装：六个平台包并发上传，全部被 npm 接受后就发布 launcher，发布流程从 8–15 分钟回到 1–2 分钟。npm job 排在 GitHub Release 之后，确保回退下载的文件已经存在。
- npm 包声明最低 Node.js 版本 `>=22`，与 `ccl acp` 的要求一致。
