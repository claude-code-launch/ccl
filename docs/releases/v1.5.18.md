## 新功能

- `ccl provider off` / `on`：关掉后普通启动不加载 provider，直接以 Claude Code 自身配置（claude.ai 订阅）运行；`ccl provider on` 或 `ccl use <name>` 恢复。`ccl ls` 会标出 `normal(off)`。ACP 不受影响。
- `ccl provider effort [low|medium|high|xhigh|default]`：设置会话起始 effort，会话里 `/effort` 仍可随时调整。`ccl provider ultracode on|off` 打开 Claude Code 的 ultracode。
- `ccl provider env` / `models` / `preview` / `effort` / `ultracode` 与 `ccl doctor` 支持 `--provider <name>` / `--acp`，不必先切换激活 provider。
- `/model` 里直接列出 provider 的槽位和模型池。
- `ccl oauth prune` 清理没有 provider 在用的 OAuth 凭据；`ccl provider rm --purge` 删除 provider 时一并删掉它独占的凭据。
- `ccl update` 会识别安装方式（npm / go install / 下载的二进制）并默认选它，`--method self|npm|go` 跳过选择；下载的二进制先按 `SHA256SUMS` 校验再替换。

## 与 Claude Code 更契合

- 你在 `~/.claude/settings.json`（或项目的 `.claude/settings*.json`）里设置的 `outputStyle`、`language`、`statusLine`、`modelPicker`，ccl 不再覆盖。
- 不再导出 `CLAUDE_CODE_EFFORT_LEVEL`，`/effort` 恢复可用；不再写 `fastMode: false`，不会撤销你的 `/fast`。
- 配了 Custom model 时，不再注入 `ANTHROPIC_MODEL`，修复会话被启动成 Sonnet、以及 `--resume` 恢复的模型被覆盖的问题。空的 Fable 槽跟随 Opus。
- Fast mode（`gpt`）由 ccl 本机代理向 Codex 请求优先服务。
- 走本机代理时默认关闭 system prompt 里的归因块，并开启网关提示头，压缩请求不再靠猜提示词识别。
- 启动时丢弃 shell 里会把会话带偏的变量：`CLAUDE_CODE_USE_*`、`ANTHROPIC_MODEL` 等模型变量、嵌套会话标记。
- 命令行带 `--permission-mode`，或运行 Claude Code 子命令（如 `ccl mcp`）时，`bypass` 不再追加 `--dangerously-skip-permissions`。

## 更安全

- `ccl doctor` 只读，不再改配置，也不再逐个测模型；`ccl doctor --probe`、`ccl provider models --probe` 才发测试请求（会计费）。
- 配置写入加锁并重读最新文件，多个 ccl 同时运行不再互相覆盖；`ccl set` 生成的名字与已有 provider 冲突时自动加后缀，不再覆盖原有 provider。
- 会话 settings 文件移到 `~/.ccl/run`（0700），退出和收到 HUP/TERM 时清理；会话日志保留 30 天 / 200 个。
- 删除当前 provider 时清空选择，不再自动切到排序第一的 provider。
- 没有选择 provider 时直接报错，不再用 shell 里的 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` 自动拼一个。

## 升级须知

- 根级 `ccl rm`、`ccl import`、`ccl auth` 已移除，这些参数现在会透传给 Claude Code。改用 `ccl provider rm`、`ccl oauth autoclaw --from-desktop`、`ccl oauth`。
- 根级 `ccl cp/mv/env/preview/models` 和 `ccl login/push/pull/status/...` 仍可用，但会提示改用 `ccl provider ...` / `ccl cloud ...`，后续版本移除。
- `acp_provider` 为空时 ACP 跟随 `active_provider`；`ccl use --acp --follow` 取消固定。
- 首次启动会把配置迁移到 `config_version: 2`：上下文预设改存为 `contextPreset`，OAuth provider 不再保存 `type`。
