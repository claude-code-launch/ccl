## AutoClaw / ZCode 订阅接入

- 新增订阅后端 `autoclaw`:`ccl oauth autoclaw` 与 `ccl import autoclaw` 从 AutoClaw 桌面端已登录的 `auth.json` 取回凭据(macOS 走 Keychain 解密),只读取、不修改、不启动桌面端。非 macOS 平台请在 macOS 上登录后再导入。
- 运行时是 CCL 自带的 Anthropic → OpenAI Chat 适配器,直接对接 AutoClaw 托管代理并按其桌面端契约发送头部,凭据过期自动刷新。
- 内建 6 个模型目录(`zai_auto`、`zai_auto-fast`、`zaicoding_glm-5.3`、`zai_glm-5.3-flash`、`tdpsk_deepseek-v4-pro`、`tdpsk_deepseek-v4-flash`),上下文 1M;`glm-5.3`、`glm-5.3-flash`、`glm-5-turbo` 等旧名保留为别名。

## 内置状态栏

- 新增 `ccl statusline`,输出 `模型 · effort · NN%`。它在 ccl 启动流程最前面被拦截:不加载配置、不初始化日志,也不会误落到计费的 Claude 会话。
- ccl 通过 `--settings` 注入自己的状态栏,优先级高于用户自己的 `~/.claude/settings.json`;`ccl set` 的 Runtime 区因此新增「状态栏」开关(provider 键 `statuslineDisabled`),这是保留个人状态栏的唯一方式。

## Command Code 下线

- 移除 `commandcode` 后端:`ccl oauth commandcode`、`ccl import commandcode`、provider type `commandcode`、握手探测与静态模型目录一并删除。已配置该 provider 的用户需改用其它后端。

## 修复

- **模型列表不再被兜底目录覆盖**:订阅后端(如 Qoder)凭据过期导致目录拉取失败时,运行时会退回内建兼容列表;`ccl set` / `ccl map` / `ccl models` 现在保留已保存的模型池,并在「本地代理」行说明原因,不再把已有模型池悄悄缩成几个兼容模型后持久化。
- **`ccl set` 订阅页面不再卡住**:loopback runtime 改为后台启动,面板立即可用,「本地代理」行先转 spinner,就绪或失败后再落定;退出时取消未完成的启动。
- 关闭 `[1m]` 上下文标记后重新打开 `ccl set`,不再被自动检测重新打开。
- Antigravity / Gemini 工具 schema 改用 `parameters`,修复工具调用参数丢失。
- Kiro 运行时把已配置的模型带入 runtime,模型列表不再为空。
- 自动压缩阈值由 80% 调整为 85%:500K 档约 425K、800K 档约 680K 触发,`ccl doctor` 显示同步更新。

## 其它

- 协议显示名统一为 `openai-chat` / `openai-responses` / `anthropic-messages`,后端限定改用 ` / ` 连接(`openai-chat / autoclaw`、`copilot / auto`、`models.dev / auto`),不再出现双重括号。持久化的 `type` 值不变。
- 订阅页面不再出现 Auto Configure / Test Connection 行:模型目录由本地运行时直接提供,订阅不再被当作普通网关探测。
- Kimi、AutoClaw 补齐空槽位默认模型(Kimi 无公开 model-list 端点,缺少默认值时运行时拒绝启动)。
- `ccl doctor` 的 AutoClaw 检查改为穿过本地适配器发一条最小请求:429 时提示套餐限流或额度耗尽。
- 调试日志新增 `content_structure`:只统计消息内容的结构与数量,不记录正文、工具参数、URL 或图片数据。
