## 新增

- 新增 `ccl sign [on|off] [--default]`：控制 `git commit` / PR 描述中的 Claude 署名（`Co-Authored-By: Claude <noreply@anthropic.com>`）。ccl 启动的会话默认关闭署名，做法与 Claude Code 官方配置一致（注入 `attribution: {commit: "", pr: "", sessionUrl: false}` 与已弃用的 `includeCoAuthoredBy: false`）；`ccl sign on` 恢复 Claude Code 的行为。加 `--default` 时同时写入 `~/.claude/settings.json`（或 `$CLAUDE_CONFIG_DIR/settings.json`），让直接运行的 `claude` 也生效；只合并 `attribution` 字段，不覆盖其他配置，`ccl sign on --default` 只删除 ccl 写入的值，用户自定的署名文本保持不变。

## 修复与改进

- `ccl update` 以 GitHub Release 的版本为准：发布流程中 Release 先于 npm 发布任务生成，此前这段时间里 `ccl update` 会提供 npm 方式，装回的却是旧版本，npm 安装的用户只能卸载重装。现在 npm 仓库尚未包含该版本时不再列出 npm 选项，只保留二进制与 Go 安装；npm 安装的用户直接原地替换二进制，保留 npm 包结构。Windows 无法替换正在运行的二进制，此时会提示稍后重试或改用 `--method go`。`--method npm` 在该版本尚未发布时会被拒绝并给出原因。
- GitHub API 不可达时（部分网络会屏蔽）仍以 npm 仓库的版本作为兜底；两者都不可用时不再误报“已是最新版本”。
