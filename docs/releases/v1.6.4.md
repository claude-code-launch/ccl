## 修复与改进

- npm 安装：`ccl` 命令直接指向原生二进制，不再经由 `#!/usr/bin/env node` 启动。Xcode 等 GUI 客户端启动 Agent 时 PATH 中没有 `node`，此前 `ccl acp` 会立即退出，Xcode 显示 `JSON-RPC request ... failed to produce a response`。现在与 Claude Code 的 npm 包相同，postinstall 将平台二进制放到 `bin/ccl.exe`，Executable 填 `which ccl` 的路径即可。升级：`npm install -g @claudecodelaunch/ccl@latest`。
- 未运行 postinstall 的安装（`--ignore-scripts`、pnpm、bun）在 macOS / Linux 终端中仍经由 Node.js 运行；运行 `node <包目录>/bin/install.js` 可补放二进制。
