## 变更

- 新增 `default`：代表 Claude Code 自身配置（claude.ai 订阅与 `~/.claude` 设置），始终显示在 `ccl ls` 第一行。`ccl use default` 让普通启动直接使用它，`ccl use --acp default` 让 `ccl acp` 也使用 Claude 官方配置。新安装默认普通模式与 ACP 都使用 `default`。
- `ccl provider off` / `on` 退役：`off` 保留为 `ccl use default` 的别名；`on` 改为提示使用 `ccl use <name>`。原有 `provider_off: true` 的配置会自动迁移为 `default`，ACP 固定在原先的 provider 上，行为不变。名为 `default` 的已有 provider 会自动改名为 `default-provider`。
- `default` 与 `ccl proxy` 不再冲突：`default` 即 Claude Code 当前的配置，代理运行时就使用代理的 provider；切换到 `default` 不再因代理运行而被拒绝。在 `default` 下执行 `ccl proxy start` 无需指定 provider：没有代理时只做提示，有代理时停止它并恢复 Claude 原有设置。

## 修复与改进

- `ccl provider cp` / `mv` 出错时只输出错误，不再附带用法说明。
