## 变更

- 没有浏览器的环境也能登录云同步：`ccl cloud login` 在 SSH、Google Cloud Shell 和无图形界面的 Linux 上自动改用 Google 设备码登录，终端显示二维码和短代码，在手机或其他电脑上打开 `google.com/device` 输入即可；`--device` / `--device=false` 可强制选择。随后用 `ccl cloud device request` / `approve` 配对或 `ccl cloud key import` 取得密钥，`ccl cloud pull` 自动解密。权限仍只申请 `drive.appdata`。
- `ccl cloud login` 的平台参数改为可选，默认 Google Drive；`ccl cloud login icloud` 等显式写法不变。已登录的远端无需重新登录。
- 全新安装默认 provider 加载为 off：尚未激活 provider 时，`ccl` 直接以 Claude Code 自身登录启动，不再报“未选择 Provider”；`ccl oauth`、`ccl set` 选择 Save & Activate 或 `ccl use <name>` 激活后自动切换为 on。已有配置不受影响。

## 修复与改进

- `ccl cloud login` 失败时只输出错误，不再附带用法说明。
