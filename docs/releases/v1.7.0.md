## 新功能：ccl web

`ccl web` 在浏览器里运行 ccl 会话，界面参照 claude.ai/code。一个对话就是一个 ccl 终端实例：每个回合起一个 Claude Code 进程，用 `--resume` 续接同一会话，所以切换 provider、模型、effort 和权限模式都在回合之间生效。历史保存在 `~/.ccl/web/sessions/`，重启后仍在。默认只监听 `127.0.0.1`；用 `--host` 监听其他地址时必须提供 `--token` 或 `CCL_WEB_TOKEN`。

- **对话**：流式回复、thinking、sub-agent 嵌套、工具卡片（diff、待办、计划）、上下文用量环、排队发送、定时发送、⌘K 命令面板、导出 Markdown / HTML、语音输入与朗读、通知。附件可以拖放、粘贴或用 ⌘U 添加，图片直接发给模型。
- **权限**：需要确认的工具调用显示为允许 / 拒绝卡片，支持 AskUserQuestion 和计划审批；权限模式可选逐次询问、自动接受编辑、计划或跳过，默认跟随 `ccl bypass`。
- **项目**：每个项目是一个文件夹。`--workspace` 可写多次，`--workspace-root` 下的每个子目录都是项目；页面上也可以“打开其他文件夹”或“新建项目”（`--lock-workspaces` 禁止）。侧栏的“项目”页列出所有项目；项目页可以编辑 `CLAUDE.md` / `CLAUDE.local.md`、`.claude/settings.json` 里的权限规则，设置这个项目新会话默认的 provider / 模型 / effort / 权限模式，并批量归档或删除会话。
- **新分支（worktree）**：git 仓库里的新会话可以在独立 worktree 的新分支 `ccl/<id>` 上运行。面板显示领先 / 落后和改动，可以合并回原分支（`--no-ff`，冲突时自动中止）或推送；删除会话时一并清理 worktree。
- **工作区工具**：文件树与编辑器（防止覆盖 Claude 的改动）、Git 面板（暂存、提交、切换分支、历史）、网页终端（默认开启，`--no-shell` 关闭，Windows 不支持）、导入本项目已有的 Claude Code 会话。
- **设置弹窗**：管理 provider（模型槽位可从 `/models` 列表里选）、订阅登录（`ccl oauth`）、MCP 连接器，以及编辑你自己的 `~/.claude/CLAUDE.md`。所有改动都经由 `config.Update` 写入 `~/.ccl/config.yaml`；正在运行的回合继续使用启动时的配置。
- **云同步**：设置里的“云同步”页对应 `ccl cloud`：登录 iCloud（macOS）或 Google Drive，查看每个远端的同步状态，推送、拉取（冲突时可强制），设为主远端，退出登录。Google Drive 在本机浏览器里授权后自动完成；在其他设备上授权时，把跳转后的地址粘贴回页面即可。
- **会话管理**：置顶、归档，侧栏按日期分组，搜索覆盖所有项目。
- **只读分享**：会话可以生成只读链接 `/share/<token>`，可随时停止分享；worktree 会话的分享页和导出会附带分支 diff。
- **订阅类 provider** 只显示 token，不显示 Claude Code 按自己价目估算的费用。
- 适配手机屏幕；Ctrl+C 秒退（再按一次立即退出）。

```bash
ccl web                              # 本机，当前目录
ccl web --workspace-root ~/code      # ~/code 下的每个项目
ccl web --host 0.0.0.0 --no-open --token "$(openssl rand -hex 24)"
```
