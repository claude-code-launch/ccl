## `ccl web` 改名为 `ccl serve`

- 命令改为 `ccl serve`，参数不变。`ccl web` 不再是 ccl 的命令。
- 数据目录从 `~/.ccl/web` 改为 `~/.ccl/serve`。已经用过 v1.7.0 的话，执行 `mv ~/.ccl/web ~/.ccl/serve` 即可保留原来的会话。
- 环境变量改为 `CCL_SERVE_TOKEN`（原 `CCL_WEB_TOKEN`）和 `CCL_SERVE_URL`（前端开发用，原 `CCL_WEB_URL`）。

## 新功能：`ccl serve --socket`

在 Unix socket 上提供同一套 HTTP + SSE 接口，给原生 App 和脚本使用，不占端口，也就不会有端口冲突。

- 不写路径时监听 `~/.ccl/serve/ccl.sock`，也可以用 `--socket /path/to/ccl.sock` 指定。
- socket 文件权限是 0600，只有当前用户能连，所以不需要 token；不会打开浏览器。
- 就绪后在 stdout 输出一行 JSON：`{"pid":…,"socket":"…","version":"…"}`，其余日志都在 stderr，客户端读到这一行即可连接。
- 同一路径上已有服务在运行时拒绝启动；异常退出留下的 socket 文件会在下次启动时替换；正常退出时删除。

```bash
ccl serve --socket
curl --unix-socket ~/.ccl/serve/ccl.sock http://localhost/api/sessions
```
