## 自定义网关与模型发现

- 自定义 Anthropic 网关新增「鉴权」选项,可在 Auto / `x-api-key` / `bearer` 之间切换,无需再猜上游校验方式。
- 自定义网关的协议列新增 Auto 起始态,按上游实际探测结果落地,而不是预选一个协议。
- 自动配置与协议探测优先沿用已配置的数据平面:模型列表只验证凭据,不代表 Chat / Responses 可用,不再因探测失败改写用户的选择。
- 关闭 Claude 自带的 gateway 模型发现,模型发现与分层映射统一由 CCL 负责,避免 `/model` 里混入未映射的 "From gateway" 条目(provider 的 `env` 仍可显式开启)。

## 修复

- 端点 URL、API Key、过滤框的退格按完整 UTF-8 字符删除,不再截断多字节字符。
- 上下移动光标时同步清除输入框焦点,避免高亮停留在已离开的字段上。
