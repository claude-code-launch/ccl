## 修复：导入的 Claude Code 会话显示子代理

从侧栏「Claude Code 会话」导入终端里的会话时，子代理的工作此前没有导入，Agent 卡片下是空的；子代理结束时 Claude Code 写下的 `<task-notification>` 还会显示成一条用户消息。

- 导入时读取会话旁的子代理记录（`subagents/agent-*.jsonl`），把每个子代理的步骤和结论挂到启动它的 Agent 卡片下，嵌套的子代理同样处理。
- 任务结束通知不再显示为用户消息，而是标记对应卡片已完成；通过 SendMessage 再次唤醒的子代理也能对应到原卡片。
- 已经导入过的会话再次导入会打开原来那份；要看到子代理，请先在侧栏删除它，再重新导入。导入是当时的快照，之后在终端里继续的内容不会同步过来。
