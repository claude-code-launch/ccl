## models.dev 模型可用性核验修复

- 区分「不可用」与「未确认」：key 已验证时 404 才判不可用，400/429/5xx 仍为未确认，不再把限流或参数不匹配当成模型下线。
- 探测按每个模型声明的 wire 协议路由（Chat / Responses / Anthropic），超时统一为 20s 以覆盖冷启动网关。
- key 验证通过后自动拉取一次 models.dev 目录并合并：已保存顺序保留、目录中消失的模型从槽位清除、自定义 pin 不动、新模型追加。

## doctor / ccl models 探测目标修复

- `doctor` 与 `ccl models` 改为探测配置的上游端点，而不是 loopback runtime（它只有 Anthropic Messages 面，Chat 形状探测全部 404，导致健康网关也被报 0/18 不可用）。
- OAuth 订阅没有 HTTP 端点，仍探测 loopback runtime。
- doctor 模型探测超时与 ccl set 对齐为 20s。

## 其他

- `ccl ls` 紧凑表去掉 CONTEXT / SLOTS 两列，保留 NAME / USED BY / TYPE/AUTH / MODELS。
- 启动器不再注入 `MAX_TOOL_USE_CONCURRENCY=3` 和 `ENABLE_TOOL_SEARCH=false`，跟随 Claude Code 自身默认（provider Env 显式设置仍生效）。
- npm `wrapper.js` 重写为 ES5，兼容无法解析新语法的旧 Node 运行时。
