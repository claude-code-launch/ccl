## Zed 订阅后端

- 新增 `ccl oauth zed`：走 zed.dev 原生应用登录（RSA 加密的 loopback 回调），不需要安装 Zed 编辑器，登录后按 Zed 计划使用其中的 Anthropic、OpenAI、Google、xAI 模型。
- 本地 loopback 网关把请求包进 Zed 的 `{provider, model, provider_request}` 信封，再按目录里每个模型的 provider 分发：anthropic 直通、open_ai 走 Responses、x_ai 走 Chat、google 走 Gemini。
- 网关不包裹外层 429/5xx 快速重试（由外层服务统一负责，避免 3×3）；`x-zed-expired-token` / `x-zed-outdated-token` / 401 在单次尝试内重新签发 LLM token。
- Zed 仅在上游数据留存条件下提供的模型默认隐藏，设置 `CCL_ZED_ALLOW_DATA_RETENTION=1` 后可见。
- 凭据存 `~/.ccl/auth/zed-*.json`（0600），`ccl ls` 中类型显示为 `zed / auto`。

## Fable 槽位

- 新增 Fable 模型层级与 `claude-fable-5-1` 路由，`Provider` 增加 `fableModel`（`ANTHROPIC_DEFAULT_FABLE_MODEL`），默认镜像 Opus。
- 槽位顺序为 opus、sonnet、haiku、fable、custom、subagent，贯穿 TUI、`ccl map --fable`、自动推荐、`doctor` 与启动器环境变量。

## Gemini

- 发送函数声明前会剥离 Gemini OpenAPI 子集之外的 JSON Schema 关键字（`$schema`、`propertyNames`、`additionalProperties` 等），避免请求被上游拒绝。

## 其他

- 直连 API key 提供商探测时按 anthropic 协议进行（`probeWireType`），不再使用其本地分发类型。
- `doctor` 的 OpenAI 兼容探测在 400 时改用 `max_completion_tokens` 重试，并对拒绝单 token 探测的网关回退到不带 token 上限的请求。
- 启动器固定 `disableClaudeAiConnectors`，不再注入工具并发与工具搜索默认值。
- models.dev 刷新时若目录与已保存池没有任何相同 ID，则保留全部已保存条目并追加目录新增项。
