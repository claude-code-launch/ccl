## OpenCode Go

- 修复 OpenCode Go 上 OpenAI Chat / Responses 协议模型（deepseek、glm、gpt 等）报 `400 MissingSessionID`：本地代理现在把 Claude Code 的 `X-Claude-Code-Session-Id` 转发为 `x-opencode-session`。只对 `opencode.ai` 生效，其他网关的请求头不变。走 Anthropic 协议的模型原本就会带上这个头，不受影响。

## models.dev Provider

- `ccl set oc` 选中 models.dev 的 `opencode-go` 后，名字保持为 `oc`，不再被改成 catalog id。只有不给名字、自动生成 `provider-xxxxxx` 时才改用 catalog id。编辑已有 provider 时切换 catalog 条目，也会保留原来的名字，不会多存一份。
- catalog id 存到新字段 `modelsDevProvider`，模型刷新按这个字段查找；老配置没有这个字段时退回用名字，刷新一次后自动补上。面板的 Provider 一行显示为 `oc  (opencode-go)`。
- API Key 尚未验证通过时，保存按钮下方会写明原因（验证中、验证失败或尚未验证），不再按了没反应、只能 Esc 退出后显示"已取消配置"。
