## 变更

- 移除 GitHub Copilot OAuth 支持。`ccl oauth copilot` 不再可用；旧配置里的 `copilot` provider 启动时会明确提示支持已移除，而不是被当作普通 API-key 端点。相关运行时、凭据与文档全部清理。

## 修复与改进

- statusline 新增 prompt cache 命中率显示（`cache NN%`，payload 提供时）。
- Antigravity 的 Claude 模型路由使用专用 schema 清洗：联合类型投影为单一类型并保留 nullable 标记，数值/布尔枚举不再被强转成字符串，无法透传的约束保留在 description 提示里。
- Gemini/Antigravity 请求转换日志与上游错误日志补充模型名，便于排障。
- 抽出共享的 loopback gateway HTTP 辅助（请求模型读取、header 复制、流式响应复制），WorkBuddy/Zed/mixed 路由复用同一实现。
