## 对齐 WorkBuddy 桌面端身份，并停止把 11140 当过期 token 刷新

### 问题

WorkBuddy 上游 403 `code 11140`（request illegal）是账号受限，不是 token 过期。CCL 把它当成 401/403 鉴权失败：刷新凭证再打一遍，等于继续对已经标记异常的账号发请求。

国内站桌面端已经是 5.8.x：`X-Private-Data: false`、`X-Agent-Type: main`，User-Agent 中间段是 `WorkBuddy`。国际站同一位置必须是 `WorkBuddy AI`，用国内品牌会被当成非法客户端。

### 修复

- 桌面指纹升到 `5.8.3` / `2.179.0`。
- `.ai` 与 `.cn` 拆开 User-Agent 中间品牌；chat 请求补上 `X-Agent-Type: main`，`X-Private-Data` 改为 `false`。
- chat 与 `/v3/config` 遇到 11140 直接返回，不再刷新重试。

已经受限的账号不会因为这次改动解封。
