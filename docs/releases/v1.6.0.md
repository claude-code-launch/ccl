## 变更

- 云同步新设备上手更简单：在一台从未同步过、尚未配置任何 provider 或 OAuth 登录的设备上，`ccl cloud login` 之后直接 `ccl cloud pull` 即可，不再要求 `--force`；原有的默认配置仍会加密备份。已配置 provider 的设备仍需 `--force` 才会覆盖。

## 修复与改进

- `ccl cloud login` 首次连接 Google Drive 时，“Encrypted storage” 显示为 `Google Drive appDataFolder`，不再显示本地缓存路径。
- `ccl cloud push` / `pull` 出错时只输出错误，不再附带用法说明。
