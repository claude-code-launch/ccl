## 网页：多标签、终端标签与新的配色字体

### 标签栏

- 顶栏改成标签栏：打开过的会话、「新建会话」草稿和终端各占一个标签，右侧固定文件、Git、子代理、终端和面板按钮。
- 「+」可以新建会话或新开终端；中键或 × 关闭标签，关掉当前标签时旁边的标签顶上来。打开的标签在刷新后保留，删除的会话会自动关掉标签。
- 只有当前标签实时接收内容；后台标签里有会话在跑时显示转圈，结束后自动停下。
- 每个标签没发出去的输入单独保存，切走再切回来还在。
- 手机上仍只显示当前标题，切换会话走侧栏。

### 子代理与终端

- 在「子代理」面板里点开的子代理会以标签打开，和所属会话排在一起，下方一条下划线标出这一组；关闭会话标签时一起关闭。
- 终端只在标签里，侧边面板不再有终端页。切走标签不会结束 shell，切回来会重放最近的输出；关闭标签才结束 shell。

### 布局与外观

- 侧边面板和对话之间加了分割线，从标签栏下方开始。
- 会话的分享、导出 Markdown / HTML 移到侧栏会话行的「…」菜单（当前会话），标题栏只显示标题。
- 对话和输入框不再限制在居中的窄列里，贴左铺满，一行能显示更多内容。
- 换成暖色的纸墨配色，正文用 Instrument Sans、标题用 Fraunces、代码用 IBM Plex Mono，侧栏按钮换了新图标；顶栏高 56px。嵌在 traefik-admin 控制台里时，两边的配色、字体和按钮位置一致。
