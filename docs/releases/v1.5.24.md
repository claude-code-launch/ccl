## 变更

- 云同步不再需要密码或设备配对：加密密钥随云端 profile 一起保存，新设备只要用同一账号 `ccl cloud login`，就能直接 `ccl cloud pull`。相应地，能登录该云账号（或持有其 ccl 授权）的人也能解密同步的 provider 凭据。旧 profile 会在已有设备下次 `ccl cloud login` 或 `ccl cloud push` 时补上密钥。
- 移除 `ccl cloud device request/approve/...` 配对命令；Linux / Windows 新建 profile 时不再要求输入密码（`--passphrase` 仍可显式使用）。
- Google Drive 改用新的 OAuth 客户端。旧客户端签发的授权无法续期，已登录的设备需要重新运行一次 `ccl cloud login`：它会重新授权，并把本机配置上传到新的云端位置。

## 修复与改进

- 没有浏览器的环境（SSH、Google Cloud Shell、无图形界面的 Linux）中，`ccl cloud login` 改为打印授权链接：在任意设备的浏览器中打开并授权后，浏览器会跳转到一个打不开的 `127.0.0.1` 地址，把地址栏里的完整地址粘贴回终端即可完成登录；`--no-browser` / `--no-browser=false` 可强制选择。v1.5.23 的设备码登录在这些环境中会报 `invalid_scope`（Google 的设备码流程实际不接受 `drive.appdata` 权限），现已移除，`--device` 保留为 `--no-browser` 的别名。
