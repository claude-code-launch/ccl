## 修复：WorkBuddy 下架模型后无法启动

WorkBuddy（含 `workbuddycn`）从账户模型目录中移除某个模型（例如 `kimi-k2.7`）后，本地仍保存着它的 provider 会在启动时报错：

```
start embedded provider runtime: configured WorkBuddy model "kimi-k2.7" is not present in the upstream catalog
```

- 现在不在目录中的已保存模型只记一条警告并跳过，runtime 照常启动，模型池按账户的实时目录刷新。
- 若某个档位（Opus / Sonnet 等）被手动映射到了已下架的模型，该映射会保留，请求会原样发往上游；请用 `ccl set` 或 `ccl map` 改成目录中现有的模型。
