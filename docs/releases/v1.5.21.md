## 变更

- 新增 `ccl proxy` 独立后台代理：`ccl proxy start -p <provider>` 后直接运行 `claude` 即可使用该 provider，多个终端共享同一代理；`ccl proxy status` / `stop` 管理。开启时修改当前用户的 `~/.claude/settings.json`，停止时逐字段恢复仍由代理管理的值，运行期间的其他修改保留。代理被强制结束（`kill -9`、断电）后，下次运行任意 `ccl` 命令会自动按恢复记录还原 Claude 配置。
- npm 改为分平台发布：`@claudecodelaunch/ccl` 只含启动脚本，原生二进制由 `@claudecodelaunch/ccl-<平台>` 可选依赖按 `os` / `cpu` 安装，每次安装只下载当前平台的二进制（此前一次下载全部 6 个平台）。请勿使用 `--omit=optional` 安装；旧版安装可直接用 `ccl update --method npm` 升级。

## 修复与改进

- `/model` 每个模型只列一次：已由槽位或 Custom 覆盖的模型不在模型池重复，槽位与 Custom 同模型时保留 Custom，多个槽位同模型时保留前一个；带 `[1m]` 的不同上下文版本单独保留。槽位别名映射不变。
- `ccl map` 可在模型目录加载后直接编辑槽位，保存时只写映射面板负责的字段，不覆盖其他 ccl 进程同时修改的连接与运行时选项。
- 配置界面随终端尺寸自适应：长内容不再撑破面板或把右边框挤出屏幕，编辑框保持光标可见。
- OAuth 刷新串行化：多个请求同时遇到 401 时只刷新一次凭据，并复用其他进程刚刷新的 token；运行时关闭时释放上游连接。
- OpenAI Chat 网关的 token 计数包含工具 schema，按路由到的模型选择 tokenizer，未知模型改用保守的字节估算。
- 模型目录不再截断为 80 个，`/model` 列出完整模型池。
- Windows：保留 Claude Code 安装目录与 settings 路径中的空格和中文；通过 npm 的 `claude.cmd` 启动时正确转义参数，并关闭 cmd.exe 的 AutoRun 与延迟变量展开。
- CI：在 Windows ConPTY 中运行固定版本的真实 Claude Code 检查 `/model`（普通启动与独立代理两种模式），并在三个平台运行真实后台代理进程与 npm 安装测试。
